AMBIENT LIGHT FOR BILIBILI
项目首页GitHub 源码

让视频色彩延伸到播放器周围

为 Bilibili 桌面播放页面添加实时氛围光，提供柔和、影院、绚彩预设，以及可调节的扩散、柔化与色彩过渡。

视频处理只在你的设备上进行

扩展临时处理当前视频画面以生成光效；主动开启宽屏去边时分析低分辨率像素。设置仅保存在浏览器本地，不上传视频帧、观看记录或设置，不添加统计、遥测或广告。

使用范围

面向桌面端 Bilibili 视频与番剧播放路径；不支持直播、移动端或第三方嵌入播放器。宽屏去边默认关闭，复杂边框或浏览器读取限制可能使其保留原画。完整验证范围与已知限制见仓库 README。

独立开发的第三方扩展，与 Bilibili 无隶属或合作关系。
